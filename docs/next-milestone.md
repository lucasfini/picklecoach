# Next Milestone

**Serve pose-estimation proof of concept using a real recorded video.**

## Scope

- Collect a small controlled set of Serve clips through the real recording flow.
- Evaluate a pose-estimation approach on those local recordings.
- Produce inspectable keypoints or measured features with provenance.
- Detect unusable input and return a retake state instead of a score.
- Keep experimental analysis behind the existing service boundary.

## Not in this milestone

- Dink or Drive scoring
- LLM-generated measurements
- Supabase or cloud uploads
- Authentication
- RevenueCat or subscriptions
- Social or coach-dashboard features

Do not replace demo coaching scores until extracted Serve measurements are stable on controlled clips.
