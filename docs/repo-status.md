# Repository Status

PickleCoach now has a polished local-first product shell for onboarding, Serve/Dink/Drive selection, guided silent camera capture with a solo-player countdown and too-short-clip rejection, review/retake, explicit analysis states, practice-only progress, and profile/privacy controls. It requests no microphone access because the analysis has no audio input.

Accepted iPhone clips are sampled on device by a local Swift Expo module using Apple Vision. The app parses 19 timestamped 2D joints, recomputes a deterministic tracking-quality gate, displays a synchronized skeleton for usable clips, and requests a retake when evidence is inadequate.

Technique scoring is not implemented. Each skill has relevant example copy, but every score, coaching explanation, and drill remains fixed demo data with prominent non-video-derived labelling. Raw clips are not uploaded, their URIs stay out of navigation and persistent JSON, pose frames are not persisted, and local history stores only validated practice metadata. Camera results move into an app-owned temporary directory that is cleared across every normal exit path and swept on startup; the player can inspect and clear each local data category from the app.

The local shell also includes serialized local-history persistence with visible save-failure recovery, malformed-data rejection, branded crash/not-found states, stale-session cleanup, original native icon/launch artwork, WCAG/VoiceOver/large-text hardening, dependency hardening, a zero-input goal-aware practice rotation, and a structured 16-case benchmark instrument with frame stepping and weakest-joint diagnostics. Scoped idle locks cover both capture and active pose extraction, while provider teardown is a final abandoned-clip backstop. Full reset keeps the routing profile intact until every other local category clears, so partial failures remain retryable. Benchmark coverage advances only from expectation-matching, visually clean physical-iPhone evidence; Simulator attempts, flagged overlays, and false S02 reruns stay visible without counting as proof. A cable collector reads only schema-validated aggregate benchmark evidence from the app container and deletes its temporary Mac copy. The current strict TypeScript and domain suite passes 35 tests, full simulator-native compilation and release-mode iOS/web exports succeed, and automated checks now run in GitHub Actions for pull requests and `main`.

The next development step is a 10–20 clip pose-quality benchmark followed by Serve phase and feature extraction—not scoring before the evidence is stable.
